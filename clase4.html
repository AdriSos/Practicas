Clase 4: Subiendo a GitHub

  • git remote add origin "URL": Vincula tu repositorio local con un repositorio remoto en GitHub por primera vez.
  • git branch -M main: Cambia el nombre de la rama principal a "main".
  • git push -u origin main: Sube tus commits locales al servidor de GitHub y establece la conexión permanente.
  • git pull: Descarga y fusiona los cambios que otras personas que hayan subido al repositorio remoto.
