Clase 2: Gestión de Ramas y Fusión

  • git branch: Lista todas las ramas locales y también permite crear nuevas ramas.
  • git merge: Une la historia de una rama específica dentro de la rama actual.
  • git checkout: Permite cambiar entre ramas.
  • git log --oneline: Muestra el historial de commits resumido en una sola línea por cada uno.
