Clase 1: Configuración y Primeros Pasos

  • git init: Inicializa un nuevo repositorio de git en la carpeta actual.
  • git status: Muestra el estado actual del directorio de trabajo y al spelling.
  • git config --list: Lista todas las configuraciones establecidas usuario, email, etc..
  • git add .: Agrega todos los archivos nuevo o modificados al spelling.
  • git commit -m "mensaje": Guarda los cambios en el historial con un mensaje descriptivo.
  • git log: Muestra el historial completo de commits realizados.
